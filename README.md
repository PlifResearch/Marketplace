# Marketplace

Catálogo de servidores MCP para a [Plif](https://github.com/PlifResearch). O arquivo `marketplace.json` é lido pela Plif quando o usuário usa `/mcp`, para pesquisar e instalar servidores.

- `marketplace.json`: as entradas. Ver [CONTRIBUTING.md](CONTRIBUTING.md) para enviar uma.
- `schema/marketplace.schema.json`: o formato aceito.

Este repositório não guarda chaves nem credenciais. Cada entrada descreve de onde o servidor vem e quais variáveis de ambiente ele pede.
